# Student Management System using Python

## About the Project
The Student Management System is a Python-based project designed to manage student records efficiently. It allows users to add, view, search, update, and delete student information through a simple menu-driven interface.

The project uses JSON file handling to store student records permanently, so data remains available even after the program is closed.

## Features
- Add new student records
- View all student records
- Search students by ID
- Update student information
- Delete student records
- Store and retrieve data using JSON
- Automatic data loading
- Exception handling for errors

## Technologies Used
- Python
- Jupyter Notebook
- JSON File Handling

## How to Run the Project

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Open the project notebook.
4. Run the notebook cells.
5. Use the menu to manage student records.
